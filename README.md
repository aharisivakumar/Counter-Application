React Counter Application

Overview

The React Counter Application is a simple beginner-friendly project built using React. It demonstrates how to use React state ("useState") to create a counter with Increment, Decrement, and Reset buttons.

The application also prevents the counter value from going below 0. If the user tries to decrement below zero, a message is displayed indicating that the minimum limit has been reached.

Features

- Increase the counter value using the Increment button.
- Decrease the counter value using the Decrement button.
- Prevent negative values.
- Display a message when the counter reaches zero.
- Reset the counter to 0 using the Reset button.
- Simple and responsive user interface.

Technologies Used

- React.js
- JavaScript (ES6)
- HTML5
- CSS3

How to Run the Project

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Install dependencies:
   npm install
4. Start the development server:
   npm start
5. Open your browser and visit:
   http://localhost:3000
